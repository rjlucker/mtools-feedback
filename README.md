# mtools feedback

Report wrong results, bugs and ideas for [mtools.co](https://mtools.co),
free developer tools that run entirely in your browser.

## Report something

[Open a new issue](https://github.com/rjlucker/mtools-feedback/issues/new/choose)
and choose a form:

- **Wrong result**: a tool gave an answer you believe is incorrect.
- **Something isn't working**: a page or control is broken or hard to use.
- **Idea**: an improvement to a tool, or a new tool.

This tracker is public. Please use small made-up examples, never real
personal data, passwords, tokens or keys. mtools never sees what you type
into a tool, so it can't look anything up for you.

## Security problems

Please report them privately, not here. See [SECURITY.md](SECURITY.md).

## No GitHub account?

Email feedback@mtools.co instead.

## About this repository

This repository holds issues only. The site's code is not public, so pull
requests can't be accepted, but ideas are always welcome as issues.
