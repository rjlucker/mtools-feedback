# Reporting a security problem

Please don't open a public issue.

- On GitHub: use [Report a vulnerability](https://github.com/OWNER/mtools-feedback/security/advisories/new)
  on this repository's Security tab. Only the maintainer can see it.
- By email: security@mtools.co

Please include the page address, what you found and how to reproduce it.
You'll get a reply within a week. mtools.co also publishes these contacts
in https://mtools.co/.well-known/security.txt.
